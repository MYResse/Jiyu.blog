# 反馈

写一些读书相关的反馈，一些心得体会，更好地去读书。

这条支线在前期肯定是会开的，到后面变成自己的学习的一个方面。或者说，自己要把它组成一个更高维度的训练，让它变成自己的内容。

不让阅读只是学习的一部分，还可以成为改变自己的一部分，提高社交，恢复精力等等许多方面。

不把阅读绑定在学习上，绑定在思考上，生活上。

事实上，虽然这篇文章的阅读量不高，但是我觉得写的很好。因为，这次写的条理十分清楚，从一个小点到另外一个小点，每个话题写了三个小点。

虽然内容不是很多，但是先条理给讲清楚了就好。所以，到后面会慢慢推进这个训练。

# 开始

4 月 23 号是“世界读书日”，今天同大家分享一些读书相关的心得体会。这次不推荐书籍，我猜会有其他的作者推荐一些书籍，又或者书商也会做一些推荐，我就不展开了。

（主要还是最近没怎么读书）

关于读书的心得体会，每个人都有，每个人的需求、方式、情况都大不相同。所以，没有必要追求非得如何，做自己喜欢的就好。觉得某些思路有帮助的就去实践，丰富视野。

我写的这些也只是我自己的，如果能够对你的阅读、读书有一些帮助的话，那是我的荣幸。如果没有的话，也希望在留言区分享你的看法和见解。**各美其美，美美与共**。

这篇文章是阅读的开始，从阅读的认识开始，慢慢地会写一些阅读相关的内容，比如如何做笔记？怎么通过阅读改变生活？等等这些选题到后面都会写一写，可能写得不是很好，还请多多指教。

# 1. 两个失误

关于世界读书日，我想说自己的两个失误。一个是在去年暑假时发起的「阅读分享会」，另外一个是今年打算做的「共读分享会」。这两个活动都没有很好地开展。

没有很好地开展理由有很多，有客观的也有主观的。比如，阅读分享会没有做下去，很大一部分是自己开学后没有时间，无法做到同步。

共读分享会，则是自己没有构思好，试图在社区里举办这个活动。有许多问题没有很好讨论，也没有达到共识。而且，这两个活动都是以英语为主题的，所以还在考虑中。

整体上来讲，举办活动的问题不难，难的是怎么参与，怎么把这个阅读机制给联系起来。还有，自己是怎么阅读的，怎么加工，怎么查找资料的。等等这些问题我一直在思考。

当然，目前有一些想法了，但是还没有具体地实践。估计要在 5 月份才能很好地实践，但是中间 6 月份中旬又有一个专业四级的考试，可能又会推迟一段时间。

虽然活动举办失败了，没有得到一个很好的结尾；但是我从中学习到的知识，所思考的空间还是很多的。这些也成为我后面如何去做外语阅读的一个来源。

当然，我也没有完全放弃这个活动，而是在想怎么组织好它，怎么发挥它的更大价值；怎么实践自己的阅读理念等等。如果活动不是我想要的，那我宁愿去做其他的。

# 2. 图书馆

提起阅读，大多数人想到的是书店、图书馆和咖啡馆。但是书籍最多的图书馆并没有和阅读太大关系，特别是在大学里面，更多的是做题、学业、考公和考研。今天借这篇文章我想和大家谈一下图书馆与阅读相关的事情。

首先，**图书馆能很好地打开阅读视野**。图书馆里面有专业类、教材类、课外类和资料类四种书籍，能够打开对这个领域的所有视角，特别是相对于书店，有更大的空间。

这些书籍不仅能适应不同的阅读需求，还可以提升阅读的档次，做主题阅读。比如，这个领域在专业人士是怎么看待的，课外、通俗读物又是怎么讲解的，对比看更容易找到异同。

其次，图书馆的书比较多，随便一个领域都可以找到不少书籍。一般较大的图书馆，走进某个书架，都可以看到相关的书籍。所以，我常常在图书馆里面转，就是为了遇见一本好书。

而且，每个专题下都有通俗到专业，从经典到前沿的书籍，能很好找到符合自己需求的书。另外，有的时候那些之前陌生的书会在经历一段时间后变得熟悉起来，这时也可以拿起来一读。

最后，图书馆里的书很适合去发现问题，做主题阅读。因为，它的书基本上是按照编号来排列的，而去一般的书店可能没有这么全，单独在商铺看无法做到全局了解。

所以，在图书馆阅读并搭建这个领域的框架是十分有价值的，能减少不少的查资料时间。另外，可以把相关的问题记录下来，等回去再用电脑搜索相关资料。

以上就是对图书馆阅读的一些看法。诚然，在咖啡馆里阅读会更加惬意；在书店里阅读会更加自然；**但在图书馆里阅读会更有收获，更有价值。**

# 3. 辽沈战役

光讨论怎么去阅读，怎么选书，而不以具体的实践案例来说明也是不行的。这次就以辽沈战役为阅读的切入点，和大家分享一下阅读时做些什么。选择三大战役中的辽沈战役只是因为我最近在读相关的书籍。

首先，阅读肯定是自己想去解决某个需求的，有动机地去阅读。那怕不是从中获得知识，也是从中获得愉快，获得慰藉。所以，阅读时思考怎么做笔记很重要。

换言之，面对难读的书时，怎么把思考过程给记录下来，整理成笔记是一个比较大的问题。而这个大问题的背后在于对阅读的认知是怎样的，是只有书本都能是阅读吗？很明显不是。

罗老师在 B 站上发现了一个视频，提到了不只是书本才能阅读，像视频也是可以拿来读的。那么，**如果我们把阅读更直观地解释成对信息的获取**，是不是加大了阅读的空间？

的确是这样的，对书本的阅读只是阅读的某个方面，不能代表为阅读的全部，特别是现在的信息丰富时代。所以，可以把书评、影视、纪录片等等拿取过来为我所用。

以辽沈战役为例，我把自己能够接触的资料分成四类：

1. 书籍：代表有《决战：毛泽东、蒋介石是如何应对三大战役的》
2. 电影：《大决战三部曲》
3. 视频：B 站一系列 UP 主做的视频
4. 搜索：其他在互联网上搜索得到的资料

用阅读的视角来看，这四类材料各有长短。比如，电影拍得很好，但是不了解具体历史经过，就会想当然的是在军事上的对比，忽略了军事以外的对比。

而书本《决战：毛泽东、蒋介石是如何应对三大战役的》很好地弥补了这个短板。通过阅读，可以更好地知道当时具体细节，敌我双方是如何判断的。但是，书本又没有特别多的地图补充。

这个对地理不好的又明显有阻碍，毕竟这是三个战役。那么，B 站上 UP 主的视频通过地球演示、沙盘模拟能够很好地知道具体情况是怎么样的，也弥补一些地理方面的不足。

但是，书上还有一些我比较感兴趣的又没细讲的，或者我不太理解的部分，这个时候就利用互联网资源，做进一步的查找。比如，三下江南，四保临江不是很清楚我就可以去查看。

### 阅读小结

从上面的情景来看，阅读里面是不是有很多问题？是的， 但阅读其实也并不是什么都准备好了再去读的。像了解这个历史，可能需要地理相关的知识，还需要对敌我双方的了解。

这些都是**储备知识**。那没有储备知识怎么办，就不读了吗？也不是，而是跟着问题慢慢地积累，这样储备知识才能完善起来。比如，营口。如果不了解这个战役的细节，可能就忽略了这个城市。

那么，需要多少知识才能做到自己想要阅读呢？我的看法是以想读懂内容为中心，慢慢地展开来。像石子丢在水中一样，波纹慢慢散开来直到看不见的地方。

所以，我会在阅读时做个划分，那些是我不知道的，那些是我要知道的，以及知道之后怎么去使用这些知识，怎么把它同已有的知识联系起来。等等这些都是在阅读时考虑的问题。

当然，以上只是阅读的一个部分，关于怎么阅读，有哪些技巧会在后面的文章中分享和展开。

# 4. 外语阅读

说完了阅读，我想说说它的细分——外语阅读。这是因为我发现公众号上发布英文相关的阅读量就少很多，发布中文相关的就会多很多。理由也很简单，天生对外语的排斥，毕竟读者也不全是英语专业的。

作为一个英语专业的学生来讲，我觉得上面的做法是对的。如果不是考试，工作面试需要，考研需要，我也是真的希望大家不要去学习英语的。

这个时候就会有人讲，学习英语有很多好处，比如说学习第二外语的好处啦，扩展知识层面等等。这些的确好，但是换另外一门语言也是可以学到的，也是可以做到的。

剩下的，就是自身需求并不是很高。的确学好一门外语可以提前获得更优质的信息，但是一个连基础信息都不看的，又怎么会去想获得优质信息。而且，这个需求已经被翻译软件给解决了。

无需更好地掌握这门语言，只需要学会如何使用翻译软件及插件就行，甚至还可以付费提供更加优质的服务。对比一看，是真的不需要花时间学习外语，那怕是英语。

为什么这么说？因为语言的工具属性已经被替代了，**至少在个体用户这个层面上被替代了**。语言是一个工具，结果工具都没了，还去学，经济上是不划得来的。

如果你还想说，学习语言不只是为了工具，不只是为经济利益，还有诗和远方？那么，我想很多人是不配的。毕竟连温饱都是问题，怎么谈诗和远方呢？

所以，总体上我是支持不学外语的，也完全可以不做外语 阅读。公众号上的文章是因为我自己思考并实践的需求才做的，基本上也都是一些语言尝试。

当然，上面也只是一些简单的思考，欢迎大家一起讨论。我会在后面专门写一篇文章来说明这个事情，那时的论据、论证肯定会比现在的要好。

### 出路

那么，我们就真的不需要外语阅读吗？其实不是，我是想说阅读外语相关材料时要想清楚自己真正的需求是什么，不要因为跟风而浪费了自己的时间。学会怎样使用工具来完成需求比这个更重要。

如果你真的是想要学习语言，想要阅读外语的材料，我也是完全支持的。毕竟，语言，从我的定位来讲，就是用来玩的，而不是做什么正经事。我配不上做，也就没有这个需求。

所以，想做一些外语阅读材料时可以尝试去了解一些感兴趣的事情。一个乐队，一个电影，一个演员，一个地方，无论什么；**只要你感觉阅读外后有收获，有价值，还想要继续阅读就可以啦。**

对于生词，我给的阅读技巧是跳过去，等到后面有必要再来查。就像书本一样，每篇外语材料也会有很多支线，如果支线并不重要，可以等到它重要的时候来掌握。

同理，语法也是一样的。不需要过多地学习基本知识而轻视了语言实践，很多时候这些知识够用就行。除非就是想做一位学者，不然把这些省下来去做更多的阅读吧。

# 5. 无限的游戏

阅读，它是一个无限的游戏。这点是为打算长期阅读的人来说的，如果只是做一些阶段阅读，为了学业，为了学校，为了他人而读的话，它就不需要是一个无限的游戏。

什么是无限的游戏？就是这个过程进展下去没有尽头，也不需要有目标；更多的是，它可以同心智、认知、品德、见识互相影响，相互组合发挥更大的力量。

这就是无限的游戏比有限的游戏要高出的地方，不是为了单纯地做一件事情，而是让这件事情变成一个长期做的。**一个是任务，另外一个是随时打开的精神花园。**

所以，如果你打算长期阅读，那么请用一个无限的视角来看待，而不要用有限的视角来看待。这样，你就会发现，那些投资的精力、时间、经费都是值得的；最终都会反馈过来的。

在阅读这个无限的游戏里，**你就是自己游戏的制定者和参与者**，你会读到什么书，取决于你想去读什么书。你想怎么排列组合已学的知识，都可以。甚至去探索未知的领域，尝试新鲜事物。

而这一切都是由你自己来决定的，游戏机制里面的奖赏和任务都是可以自己来设定和调控的。保持阅读，你也将实实在在地获得想要的。换言之，你就是自己精神花园的总设计师。
