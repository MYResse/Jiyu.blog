# 引言

原本今天没有打算写文章，因为我打算明天或者后天再写一篇关于用 AI 学习英语的文章，并为此做一些准备。

今天我正好过完了《鸣潮》3.2 上半期间更新的内容（其实也不算完全过完）。过完之后，我发现这个游戏的内容真的非常值得吐槽一次。

在我看来：

1. 如果这次游戏剧情做得非常烂，我反而不屑于去吐槽它，因为实在没有必要。
2. 如果这次剧情做得非常好，我也没必要特意写文章去夸它一遍。

正是因为这次剧情写得中规中矩，或者说里面有些值得商榷的内容，才引发了我写一篇文章的冲动。
# 游玩经过

先简单说一下游玩的经过。

我自己是用平板玩的，相当于在移动端体验。因为我没有专门的台式电脑或游戏本，所以整个游玩过程中卡了好几次。

特别是从昨晚到现在，这两天里闪退了至少有七八次。最主要的问题是主线进行到学院部分时经常卡死退出，导致我中间的体验非常断断续续。

另外一个原因，就是这次主线任务中掺杂了太多次的活动任务。也就是说，如果不完成这些活动，主线就无法推进。

对于我来说，我的习惯是先完成主线，再去处理活动任务或支线任务，这样有一个清晰的先后顺序。但这次的设计明显要求玩家必须先做活动才能继续主线。

我跟朋友吐槽说：这次做主线的体验就是走走停停，仿佛正全身心投入地看剧情，却不断被插入各种小广告，被迫停下来去做别的事情。

我不知道这是玩法设计上的差异还是其他什么影响，但这确实非常打断我在整个主线过程中的剧情体验。
# 游戏设计

在主线任务中加入活动任务，这种游戏设计在我看来其实非常不合理。

虽然我也会在 B 站或抖音上刷一些《鸣潮》主线的切片或者二创视频，但不论二创做得多么有特点、吸引人或可爱，游玩游戏本身最关键的一点，依然要有扎实的主线剧情铺垫。

这也是为什么我觉得 3.1 版本（特别是上半部分）的主线做得非常好。虽然 3.1 版本的剧情时长实际上不一定比这一部长，但它的节奏并不拖沓，每一步的营造都非常得体。

相比之下，这一部剧情因为强行加入了活动任务，导致整体过程显得特别拖拉：

1. 角色塑造受阻：虽然我对二次元游戏里的每一个角色都会认真对待，并不会特意偏爱某一个，但这种破碎的设计确实导致了角色塑造不够成功。
2. 玩法逻辑值得商榷：在游戏里，无论是追求强烈的体验过程还是其他感受，最核心的任务就是要把主线剧情做好。主线是后续玩下去的最大动力，也是玩家对角色建立第一印象的关键渠道，但这一次显然没有处理好。

我认为这次游戏的剧情文本之所以没能给人那种“电影级”的享受，原因主要有两个方面：

1. 设备或环境等外部因素的影响
2. 观影过程中的心流不断被打断

这种明显的拆分与分隔，最终导致了人物塑造过程中出现异常，也让整体的剧情体验大打折扣。
# 游戏主题

第二个方面就是这一次版本的有些主题其实是比较沉重的。从心理学角度来讲，这个主题甚至可以进一步引申到校园暴力等相关主题。

我觉得这个主题其实是非常值得去讲的，也就是说，人物角色哪怕他是一个二次元人物，也可以塑造得很好，因为主题非常沉重，而且非常宏大，特别是从精神内核上来讲。

一方面，这个主题主要是讲游戏角色西格丽卡在整个会典活动中，可能遭受了一些非议，或者说来自他人的过度期待，然后进一步影响了一些问题。

这里面，暂时定为反派的“残星会”成员，他们代表着另一种可以去逃避。之前有一部日本电视剧叫《逃避虽然可耻但有用》。这也是为什么我在看完整个主线剧情之后，觉得非常不能说是割裂，但确实是有一段差距的原因。

它一方面想要塑造你如何面对其他非议时，怎样决定做自己的决策。这个整个语言过程或者说语言文本并没有很好地展示出来，也就是说，它没有凸显出这个人在解决矛盾冲突时是依靠着什么。

虽然这一部分大部分由游戏的主角漂泊者来承担了，但并没有很好地让游戏里面正式版本的剧情主角西格丽卡来承担。这就导致我们在玩的过程中，我自己都吐槽有点像心理辅导员去做这个事情。因为我把自己代入到漂泊者的节奏中，就会发现这个事情。

但是我们玩家想要认识到的西格丽卡这个主角，她并没有表现出他能够这样做。虽然他中间可能会通过一些其他方式，比如说玩游戏、观赏小鸟等去排忧解闷，但是她总体上没有表现出一个很好的去处理斗争甚至去反抗的能力。

因为在整个篇幅里面，她都没有表现出能发起冲突，解决冲突，只有在最后 BOSS 阶段冲突的时候才会发起冲突。

讲到如果这个情节的话，应该更早一部分就应该要被提出来。但是因为二次元世界里面所有世界都是美好的，所有不好的都是虚构的，这就非常难以打破里面的，就像戏剧里面的第四面墙一样，它非常难以打破中间的隐晦冲突。

这也就是为什么我整体游玩的过程中，并没有对西格丽卡有多大的共鸣，反而对里面的 BOSS“残星会”所代表的那种“逃避虽然可耻但是很有用”产生了一些同情或者说共鸣。

这是因为在现实世界里面，很多事情确实并不是说你去大声反对或者说之类的，就可能就能够推卸掉。但是你逃避掉了，确确实实是能够起到一些很大的帮助。甚至很多时候别人的期待它就是本不该有的期待。

就比如说我们以前可能会经历过“这个孩子可能是村里的希望”之类的。我们也知道像我们这种小镇做题家出来的时候，他可能很多时候他并不能够去回应这些期望，甚至他不能像时代一样去回应。

虽然里面也有安排，比如说西格丽卡这个角色，她的妈妈就会安排一些“不用承担这么多”或者说“你失败也没有什么”。但其实这过度的保护也好，或者说是期待也好，它并没有去形成一个很好的变化。因为如果真正去做这个事情，能够有很好的保护，是不会出现这个事情的。

所以我们可以假定为游戏里面剧情中的美好跟现实里面的，如果分十分之一，甚至我认为分二十分之一到现实里面的美好，那么这个人物都不会有那么大的问题，都不至于有那么大的心理问题。

如果在中学的教育里面，或者说在高中大学里面，他甚至在整个人生过程中不用被过度期待、过度的期望的过程中，他都不会有那么大的问题。但事实却戛然相反。

在我们看来，游戏里面的西格丽卡如果是放在现实生活中，那就是相当于她已经是非常优秀的那种生活环境了，但确实还表现得不是很好，这种落差就会相当大。当然我会在后面再解释一下这部分原因。

所以在整个游戏的过程中，反而就是现实世界跟游戏世界跟二次元世界里面的冲突这一个主题，它在文本上没有写得很好。

然后角色在设计的过程中也是有待商榷。当然我也在反思这个话题，这个主题是比较沉重的，因为如果整个游戏全面展现出来是不太方便的。它如果整个展示出来就会有一些进入到更深层次的一些内容。

所以我也在思考，可能是游戏制作组为了规避这些不必要的麻烦，就没有做。但确确实实是少了这些痛苦也好，或者说少了这些直面的冲突也好，也就导致这个游戏整体的主题升华并不是很恰当。
# 游戏文本

这里也要简单提一下游戏文本的内容，这也是我们分析游戏主线剧情的一个主要来源。因为主线剧情中会有一些人物动作描写，但最核心的表达还是来自于剧情文本。

这次的剧情文本能明显感觉到，在 3.1 版本那个非常难受、或者说类似 Bad Ending 的结局之后，作者这次想让整体基调偏向 Happy Ending，减少游玩过程中的不适感。整体状态仿佛是想让大家去参加一个庆典活动。

但这种处理方式很难引起共鸣，原因有两方面：

1. 时间节点的错位：上个版本恰逢过年期间，在游戏里开展庆典活动非常契合氛围。但现在大家都在工作，甚至包括我自己也在处理一些琐事，很难再产生那种庆典式的共鸣。

2. 角色表现与主题呈现：文本中关于角色的表现并不是很好。我本希望这次的主题能表现出一种“鸡蛋破壳”般的新生状态，象征一个新生命的诞生，但这种状态应当是通过斗争获得的。

后来我也慢慢接受了一个事实：像二游（二次元游戏）的剧情文本，为了商业化必须做出牺牲。它不可能像经典文学或名著那样去直面冲突，它做不到，也没有办法去做。

所以很多时候，我们需要考量游戏制作组如何去平衡这种中间地带。这涉及到游戏深度的瓦解，因为制作组必须考虑到：

* 一方面，游戏是商业产品，需要盈利并照顾大众口味。
* 另一方面，在讲故事的过程中，确实会出现表达上的问题。

因此，包括后面活动在内的这些游戏文本，我觉得可以游玩，但并没有留下特别深刻的印象，整体的连贯性给我的感觉也不是很好。
# 游玩思考

我玩《鸣潮》这个游戏大概有一年半了，大概是从去年开始，中间一直持续在体验游戏内容。

在和朋友讨论的过程中，我发现随着年龄增长，二次元游戏已经很难让我产生共鸣了。不管是看漫画还是青春文学类的主题，都已不再能吸引我。

这主要是因为这次的版本更像是一个面向学院、大学生活的版本，但我去年就已经大学毕业了，也没有考研，对学校里的很多内容已经不再熟悉，也很难引起共鸣。如果这个游戏是在我大一的时候推出，我可能会非常有感触。

由此可见，国内的二次元游戏确实有一定的受众倾向，更倾向于年轻群体，而我的言外之意就是：**我已经不再年轻了**。

另一方面，我一直将二次元游戏当作通俗小说或科幻小说来看待。我原本期待这个版本的剧情能讲述一些宏大的背景故事，但通篇看下来，主题还是围绕校园霸凌或自我主体性相关的内容，这让我没有得到很好的娱乐享受。

我也在感慨，很多游戏是需要时间沉淀的。这也是为什么我喜欢玩单机类游戏，哪怕它们已经发售了七、八年甚至十年，在游玩过程中依然能体会到很多深层次的东西。但二次元游戏不同，它每个版本或周期都有商业流水等各种需求，导致它很难像单机游戏那样纯粹。

我现在读通俗作品时，会更倾向于科幻或文学类幻想，很难再去读儿童文学或青春文学。因为中间经历了许多事情，那些阶段已经体验过了。

就像我现在看自己高中甚至大学时的笔记，深知那个时间段已经回不去了。这也解释了为什么在动漫方面，我更喜欢早期的作品或是奇幻类动漫，而不喜欢校园类。

我的校园生活并不精彩，中学时代过得也不是很好，不会产生那种美好的幻想。我更希望从个人成长或心理学的角度，让这些往事就这样过去。

当然，《鸣潮》后续可能还是有游玩价值的。随着人的成长，玩游戏的心态确实发生了变化。

还有一个很重要的改变是：以前我玩游戏哪怕觉得再好，都不会专门去写影评；**但现在我发现，无论游戏玩得好坏，我都会录一段音频并转成文字，去表达我的思考**。

我觉得只有这些内容才是能够真实保存下来的。就像看一部电影，我可能觉得它很好却说不出原因，那我就通过这种方式慢慢去拆解、去讨论。以前我不擅长跟人讨论，但现在我愿意通过写文章的方式来发表自己的见解。
# 结束语

最后做一个总结。

《鸣潮》1.2 上半的剧情主线，在我看来更倾向于一个中规中矩的表达。它在话题主题的选择上，对游戏制作组来说其实并不好平衡：

1. 表达得过重、过深：对于受众群体来说并不是件好事，无法起到游玩娱乐性的作用。
2. 表达得过轻：就会像这次版本一样，单纯得像样板戏，虽然美好但没有引起剧烈的冲突。

所以这次的剧情主题确实比较平淡。如果你是非常喜欢享受游戏的玩家，可以去完整体验；但如果觉得不是很享受，直接跳过问题也不大。

有时候跳过主题、跳过对话，感觉就像跳过人生一样。我自己也开始对此产生了一些思考和讨论。

以上就是今天全部的文章，祝好，各位读者。
